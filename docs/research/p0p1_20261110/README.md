# P0/P1 实验补充

2026-11-10。五种策略、四段已暴露开发视频共 20 组 PYNQ-Z2 实机结果全部取回并复算。100 个输出文件哈希与板端终态一致；没有为补充报告重跑模型。

人工已知方向总数为 12／12／11／12。U0 目标为 2.5 Hz、无补检；其他条件目标为 5 Hz。L 为最新帧、C 为历史偏好、1 为带条件局部补检，实际观察率与调用量另记。20 轮均满足原回放时限。C0/C1 共请求历史帧 15 次，全部被年龄限制切回最新帧，不能据此证明历史选择有效。L1 与 C1 的总调用接近，但源帧时刻和全局／局部分配不同，不是严格匹配预算的因果对照。

[逐案指标](VERIFIED_METRICS.json)保留全部计数、调用、时序和失败，不填事件 F1。研究结论优先落在局部补检与观察预算的取舍；四段开发片的 47 次人工总数不增加独立测试样本。

[数据审计](DATASET_AUDIT.json)由 Slurm133415 完成：图像／标签文件 16760 项通过，128 张校准图均来自训练集；部署归一化 QDQ 图和训练检查点匹配。原误报来自比较归一化前后两个图。[来源 block 核验](SOURCE_BLOCK_AUDIT.json)发现 10402 个来源记录均按原编号每 100 个分组，block 不能用作录像会话标识。RGB 重复项来自历史清单；本轮没有重新解码检查近重复。

[硬件来源](BOARD_FIRMWARE_PROVENANCE.json)绑定在用 XSA、bit 与 HWH；资源利用率和板功耗仍无实测报告。源数据、模型、板端完整日志继续放私有归档，没有加入本次仓库补充。
