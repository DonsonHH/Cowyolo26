# 低分辨率漏计：先补稳定观察，单改ID关联还不够

2026年10月29日。已只读检查27组整幅输入缓存，并补充12组既有固定通道裁剪缓存。**主要192直角seed26案例的6条未计开发参照轨迹，即使辅助串接原始框，仍不能满足当前计数条件；因此仅调整ID关联不足以解决当前问题。**

这个结论针对已有开发片段和固定框对应规则。人工确认的是8912–10873帧总数12；本轮没有新增逐帧人工框、逐事件身份标签或独立测试，以下不报告正式检测召回或事件F1。

## 1. 如何分开检测、位置和跟踪影响

参照来自此前640输入数到12头的固定链路：12条开发轨迹、581个原图坐标框。其中12个早期框由链路实际允许的上一刻度观察补入，均与原始640框按已有轴位置唯一对应。参照自身重新计数，12事件及发生刻度与原记录完全相同；它仍是模型轨迹，不能升级为人工逐事件真值。

每个刻度分别将低分辨率原始框、确认后的框与参照进行一对一空间对应，固定IoU0.5，再用预先固定的0.3作敏感性控制。模型、conf0.2、ROI、BYTETracker、A<0.4／B>0.6、连续3采样及2秒最大间隔全部保持。检查以下三条离线辅助路径：

| 辅助路径 | 保留的模型信息 | 用于判断 |
| --- | --- | --- |
| 框覆盖＋参照中心 | 哪些刻度有对应原始框 | 框覆盖是否足以形成现行计数证据 |
| 原始框中心＋辅助对应 | 原始框的中心和ROI归属 | 中心位置／稳定区域的影响 |
| 确认后中心＋辅助对应 | 跟踪后框及实际允许的上一刻度交接 | 确认／跟踪框覆盖的影响 |

这些路径使用开发参照帮助串接，不能直接部署，也不是新的奶牛身份标签。它们**不是逐层单调上界**：78个分析条件中，整幅输入有13个条件的实际计数高于至少一条辅助路径，因为对应门限、参照可见范围和框中心不同。不能把两条辅助路径的差直接叫作某阶段的真实错误数。

## 2. 主要192案例：原始框已经缺少关键区域证据

主要模型在查看本轮诊断前就固定为`S192_rot90_seed26`，不是挑选最好seed。它实际计数6；三条辅助路径分别计数6、6、5。所有实际6事件均有事件发生刻度的空间对应。以下是未计入的6条开发参照轨迹：

| 参照轨迹 | 有对应原始框的刻度／参照刻度 | 框覆盖辅助路径的最长连续A／B采样 | 当前不足 |
| --- | ---: | ---: | --- |
| 93 | 34/47 | 2／22 | 入口A不足3 |
| 94 | 3/15 | 0／2 | 入口与出口均不足 |
| 96 | 33/52 | 2／8 | 入口A不足3 |
| 103 | 23/35 | 0／20 | 入口A缺少对应观察 |
| 98 | 27/66 | 6／2 | 出口B不足3；时序间隔另保留 |
| 102 | 51/75 | 1／15 | 入口A不足3 |

这6条在IoU0.3与0.5下，辅助路径均未产生完整向下计数。它们并非整段没有检测：例如轨迹102有51个对应框，仍缺入口区域的连续证据。轨迹96、98等也存在ID分段，但辅助串接后仍未完成现行条件，不能把漏计全部归因于换ID。

5Hz下3个相邻采样点从第一点到第三点相隔0.4秒。后来在B区域出现很多框，无法补回已经错过的A区域稳定观察；仅提高整段平均定位指标并不保证通行计数改善。

## 4. 既有固定裁剪缓存提供的控制

随后只读此前已有的12组固定通道裁剪缓存，边界仍是原图`[870,0,1920,1440]`，没有重新搜索。以下比较同一旧权重、同一尺寸的整幅／裁剪结果，避免把换权重和换输入混在一起：

## 5. 下一步只先改变输入范围

下一轮将把**已经固定的同一通道裁剪**应用到全部15个新模型，配对此前整幅输入结果。保持权重、192／256／320、置信度、采样、跟踪和计数规则；保留Toros反向压力对照及全部seed。预计新增39810图条件检测，不重训、不搜索ROI或调稳定样本数。

若新模型也获得更早、更连续的区域观察，再将声明好的候选编译到O8，核对量化后实际视频计数和5Hz时限；若未改善，保留失败并转向入口截断／遮挡样本准入。身份及RF联合评价仍需独立参考。原640人审12头版本和O8首轮实机实现证据继续保持。
