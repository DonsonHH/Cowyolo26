# 普通俯视训练集覆盖审计与配对训练入口

2026年10月30日。上一轮25350次输入对照没有改善完整通行，两个变换均不采用。本轮先检查训练材料，再选择一个训练侧干预。

1. 只读取当前6809张普通俯视训练图及8888个发布方旋转躯干标注。验证集、1400开发保留、622最终日期候选及源视频像素均不进入本轮覆盖审计。
2. 在新统计前固定代理定义：旋转躯干可见区域内的Y亮度分布；其外16像素方形环带、排除所有其他躯干标注后的背景对比；可见标注在192／256／320缩放后的短边与面积；躯干多边形两两重叠和画面裁断。低亮度中位数≤80、低背景对比≤15、192短边<24像素、两框相交占较小可见区域≥0.1分别计数，也保留连续分布，不据阈值强行断言数据缺失。
3. 标注是旋转躯干矩形，不是像素分割或遮挡等级。“暗色代理”“重叠代理”“裁断”分别报告；不能由重叠直接认定真实遮挡，也不能由低亮度直接认定牛的毛色。当前准入的五字段标注没有独立遮挡类别。
4. 对全部源图校验哈希，保存8888份区域／背景亮度直方图、连续指标、日期分组、成对重叠，以及前32张固定图像的实际Y像素与掩码控制。独立重算几何、直方图分位数、阈值计数和聚合；不运行检测或身份网络。
5. 样例按预先固定规则选择：三份最低区域亮度、三份最低背景对比、三份最大重叠、三份最小192短边，按annotation_key打破同值，按次序排除重复，共12份。它们说明指标测了什么，不作独立准确率。
6. 审计结束后再固定训练干预及配对协议。保留192直角三seed、同一官方初始化、训练步数、常规增强和计数规则；新权重全部冻结后统一评价。任何新增训练都另建目录、先做真实前后向短跑，不把本轮审计写成已训练或已改善模型。
