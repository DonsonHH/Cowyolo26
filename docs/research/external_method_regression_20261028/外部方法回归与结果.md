# 当前计数方法在既有公开参考片段上的回归

2026年10月28日。源片上的两项关联控制均未新增完整事件，因此本轮固定方法，回到已取得的Toros公开参考检查跨视角退化。**这是已经使用过的外部诊断片段，不能重新称为独立测试。** 参考仍是发布方轨迹按原冻结规则导出的6次B→A完整通行。

本轮有一处有限增量：**五轮微调模型的检测缓存加入Lost低分恢复后，匹配由2次变为3次，漏计由4次变为3次；官方模型四条方法路径均保持6次匹配。** 固定评分规则下，所有条件均没有额外预测或方向错误。但是新增匹配附近出现同一可见牛的重叠双ID，因此不把这项结果直接采用为最终改进。

## 1. 比较的是方法，权重没有重新训练

使用原官方YOLO26n和OpenCows五轮微调模型已经冻结的检测缓存，输入边长320、检测置信阈值0.2。没有运行新的检测前向、训练、选阈值或根据参考结果修改方法。

它们是原有两套检测模型，**不是荷斯坦源片中最新的三个Cows2021权重**。本轮回答“计数／关联改动在既有另一视角的缓存中发生什么”，不证明最新三权重已经跨场泛化。

Toros沿用1920×1080、30fps、479帧、横向x计数及垂直ROI0.1–0.95；区域0.4／0.6、连续3帧、最大观察间隔2秒和事件匹配容差2秒全部保持原协议。这里3采样跨2／30秒，不能与源片5Hz下的0.4秒稳定观察时长混为一谈。没有为追求分数改变原参考。

两模型各运行三种跟踪器（原安装版、纯IoU第二阶段、纯IoU且允许Lost），每种分别保留原计数和入口观察交接计数，共6次完整跟踪回放、12条评分路径。下表列出主要的两模型×四方法8条件，另外4条仅确认观察的诊断路径在CSV中完整保留。

官方模型本片段F1为1.0；五轮微调原F1为0.5，Lost路径为0.6667。分母只有6次参考通行，片段此前已用于诊断，结果不能表示总体牧场准确率。

五轮微调新增时间匹配对应参考ID1（参考帧110、3.667秒），预测ID1在125帧、4.167秒输出，延迟0.5秒，处于原2秒容差内。原来匹配的参考ID7、17继续保留；参考ID14、16、22仍漏计。这里的参考ID和预测ID数值相同是巧合，身份对应不能仅凭编号判断。

仅确认观察、关闭入口交接的Lost诊断路径也得到3TP／3FN。这说明本片段的增量来自关联连续性变化，而不是启动观察交接；两者在荷斯坦源片中的作用继续分别记录。

## 3. 新增匹配的状态与重叠ID风险

原微调与纯IoU路径中的预测ID1在112帧后失去输出。Lost路径在120帧接回分数0.216的实际低分观测，距上次观察8帧；121、122帧仍有缺口，123–125连续三次进入A区后，保留的B起点使125帧产生B→A事件。[本机三路径完整组件重放和状态](<../../../research/external_method_regression_20261028/results/pilot_case_states.json>)与服务器输出一致。

[原纯IoU与允许Lost的新增匹配案例](<../../../ARCHIVE_CONTENTS.md#omitted>)

橙色为发布方参考ID1的框，绿色为被检查的预测ID1，青色为其他实际跟踪输出。图像核查发现：**120帧的预测ID1和ID8同时覆盖同一头左侧可见牛，两预测框IoU约0.858。** ID1随后报出125帧事件，ID8本片段没有产生完整事件，所以事件评分仍FP=0；这没有消除重复轨迹。

[重叠ID审查记录](<../../../research/external_method_regression_20261028/results/overlap_case_review.json>)保留两框、分数、彼此IoU和对应发布方框的几何值。发布方框与训练模型躯干框口径有差别，后者几何值只用于案例核对，不是新的mAP或全片个体正确性认证。[不带预测的五帧源图](<../../../ARCHIVE_CONTENTS.md#omitted>)。

这暴露一个后续验收要求：低分恢复不仅要检查事件是否补回，还要检查旧ID恢复时是否与已经存在的新ID并存。单靠每个检测的一对一匹配，不等于每个真实动物只有一个活动轨迹；当前不根据这一个案例立刻添加／选择新的去重门槛。

## 4. 验证范围

原两模型的全画面跟踪框、ROI轨迹和6／2事件逐项精确复现。由原始1775条发布方GT、9个轨迹ID重新导出6事件，并与原冻结参考完全一致；原边界／截断等质量发现继续保留。

12条计数路径由另一实现独立复算，2874个更新、6251条ROI轨迹观察及95次确认前观察交接核对。评分以穷举一对一分配独立验证最大匹配数量及最小总时间差，所有TP／FP／FN／方向错误与固定评分器一致。不同方法的时间匹配不被用来反向挑选参数。

两批交付共87个清单条目，分别绑定协议、缓存、源码、评分和案例图；5张原图、10张叠图完整解码，五原图接触表及主6对照面板已视觉核查。其余4张辅助叠图仅声称完整解码，不扩大为已逐图人工审阅。作业130293、130294均COMPLETED0:0，均只请求CPU。

## 5. 研究决策

保留Lost恢复的有限回归增量，同时保留重叠双ID风险及源片无新增事件的负结果。**五轮微调即使到3／6，仍低于官方基线6／6，当前不能作为最终检测模型。** 不能用一处事件增量推翻此前对域泛化、训练组成和标签口径的判断。

荷斯坦原片当前29组冻结条件和12／11／11预测未改变；外部12条评分独立保存，没有混入原片索引或汇总成跨牧场准确率。原片独立人工JSON、新会话及真实双向条件继续等待／补充，PYNQ-Z2连接与版本按用户安排稍后提供。
