## 重算

在CPU Python环境安装NumPy（已检环境为Python3.13.9/NumPy2.2.6），运行：

    python recompute_companion.py --root .

脚本先核PUBLIC_MANIFEST全部文件，再用实际运行摘要与事件台账重算已确认方向总数。未完成案、不存在人工参考的案均保持未评分；每轮四片分别汇总，不把重复当独立样本。模型前向为0。完整软件测试另需OpenCV/LAP等，环境记录与189项cloud/ARM日志已附。
