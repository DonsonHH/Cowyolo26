# 最终论证：固定预算下的观测与出生几何

研究问题：相同检测图和真实调用配额下，新的全局观察与同图局部核验如何影响奶牛完整通行总数、时延及执行稳定性？

现有方法已覆盖粗到细检测、自适应尺度和流式调度。本文不以YOLO新版本、首次放大或新的FPGA架构作为创新；讨论具体的计数任务、调用分配及同图框融合。

证据链：

1. 四段已曝光开发视频共47次已确认通行，两个方向分别在不同相机出现。重复不增加独立动物数；未确认反方向为未知。
2. 固定预算A/B共16案，每次重复A为11、12、9、9，MAE1.50；原局部框B为12、11、11、12，MAE0.25。B改善三片、恶化一片，NN配额完全相同。
3. 同一B观察流掩蔽局部测量，恢复11、12、9、9；仅更改出生阶段的坐标与分数组合，固定输出控制为12、12、11、12。控制不反馈提案，不能当作真实新部署。
4. 真正闭环V7复测四片各两次均12、12、11、12，MAE0；原时序参考7/8，最慢事件发布1.154秒。额外SD空通道案丢失计划帧，整批保留FAILED，不拿部分0评分。
5. 不改算法的RAM输入/日志对照两案完成：负例候选300次、预测0但无人参考；最长正例325次、计12。527共有调用输入/raw相同，预载与回盘在流计时外，不证明持续SD发布已通过。

局部图只提供被接受的真实分数，出生坐标保留同图真实全局seed；Endpoint位置仍为真实局部检测。同图一次update、预测位置不计通行。默认关闭的开关保留旧行为。
