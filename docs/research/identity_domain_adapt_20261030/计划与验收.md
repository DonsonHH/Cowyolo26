# 身份域适配配对实验：同起点、同预算、匹配图库规模

2026年10月30日。当前Cows2021图像检索Top-1与拒识风险不足，下一步检验新域监督是否有帮助。本实验包含训练和已看开发材料的评价；不把开发改善当作新的最终结果，不打开新的最终牛号／保留日期。

1. 起点固定为已上板的`C_letterbox_trained_seed26`，encoder SHA为`6653555c…ded06b8b`。M分支只用原580张MultiCam训练图继续训练；C分支只用此前540图研究以外的16个Cows2021作者牛号。按固定SHA选16个训练牛号，其余20个合格牛号留作未来最终身份候选，目录和日期元数据可读，像素本轮不开启。
2. Cows训练图只取≤2020-02-27、每ID最多32图，按日期轮流、日期内文件名顺序取图，至少两个日期。原作者将这部分称Identification/Test，本项目明确把其中16个未用ID改作监督训练；不能认领为复现作者原身份测试协议。新训练ID与已有Cows120校准／开发ID及未来20候选ID互斥，03-05至03-11日期仍不打开。
3. 两分支均从同一固定encoder开始，seeds26／27／28各跑300次AdamW更新、每步32图（8个ID×4图、跨至少两日期正样本），224身体增强、CE＋batch-hard triplet及学习率沿用原身份研究。类别头只在各自来源内学习，不将跨2020／2023未映射数字当作同一或不同物理牛。训练身份数为M20／C16；场景、图像和ID数均随来源变化，不将此结果解释为只改变单个摄影因素的因果证明。
4. 先做两分支各1步CUDA预检，丢弃预检状态，记录64图前向和2次预检更新。正式六次训练各300更新，共1800；只取末次encoder，保留所有seed，不按开发正确率选epoch／seed。每步记录图像索引、日期、输入hash、损失与梯度；六个末轮checkpoint共同冻结后才允许任何校准／开发特征前向。
5. Cows校准仍用原20注册／20未知ID、180图。开发评价按原40注册ID分为两个固定20ID组，每组60张注册查询＋同一120未知查询；每组图库20ID、每ID3图，与校准图库大小相同。两个组全报告，重复未知查询不当独立新牛。原40ID完整图库作为压力附录，保留所有原4条件数字。
6. 每个新模型同时报告原MultiCam阈值迁移与仅由Cows校准冻结的新阈值。所有六模型新阈值共同保存后才读开发评价特征。新模型还跑原MultiCam30图库＋60查询的保留能力控制，沿用原阈值；这些图早已用于开发，不称未见最终测试。合计六模型每个540＋90图，共3780次评价／校准前向，无隐式预热。
7. 采用决定不依赖“单轮数好看”：主seed26事先固定，仅保留研究候选，不自动改板端模型或阈值。逐模型C／W／U、未知FA、Top-1、按牛区间和同牛配对差完整报告。即使开发改善，也要先完成新权重的NCNN一致性与实机，再冻结未来最终ID评价。原12头事件永久身份、独立通行和现场RFID仍待补。

网络下载只取上述训练图；训练和推理全部经Slurm，不在mu01持续计算。复用原环境与文件，新增任务目录，不动其他作业、不删除旧结果。新像素逐图CRC／解码hash及与原身份输入的精确重复核查通过后才训练，坏图／跨ID重复不按模型成绩替换。
