# 双ID冗余审计：计划与验收

2026年10月28日。承接[外部方法回归发现的120帧双ID案例](<../external_method_regression_20261028/外部方法回归与结果.md>)，对已有六组完整跟踪输出做只读诊断。本轮不修改检测、关联、计数，不按结果增加去重门槛。

## 固定诊断口径

范围为Toros原视频0–478帧、30fps，沿用垂直ROI0.1–0.95。每帧不同已确认预测ID构成无序对，框IoU至少0.5时列为“高重叠双ID候选”，每对每帧记一次；这不自动等于两ID属于同一真实奶牛。

发布方原始轨迹框裁剪到1920×1080边界。每个预测框分别取唯一最高IoU参考：两预测指向相同发布方ID且各自IoU至少0.5时标记“主口径几何支持”，0.3作为此前已使用的敏感性口径。并列最高IoU记录为歧义，不强分身份。躯干预测与整牛参考的范围差异保留，因此不把这个支持指标当标准跟踪重复率或身份认证。

同时检查两套原始检测缓存，以相同ROI／0.5重叠标准统计原始双框。预测对若能分别对应两个不同原始框、分数相同（差不超过1e-7）、预测／原框IoU各至少0.9，则进一步检查原始两框是否也重叠至少0.5。这个保守链接能确认部分冗余在检测输出中已存在；链接失败不证明问题由跟踪器新增。

同一无序ID对在连续源帧出现构成一个片段，所有长度均保留，不按时长筛除不利结果。分别报告“有候选的帧数”“候选对×帧数”和“连续片段数”。检查两ID是否在片段内、全片分别产生事件，但不从几何重叠自动删除任何ID或事件。

## 验收步骤

1. 在审计前绑定原六输出、两原始缓存、发布方GT和固定参数SHA；完整保留原6／2→3事件评分。
2. 扫描全部2874个条件帧，不只挑120帧；列出全部高重叠候选和连续片段，分别报告0.5／0.3支持及原始框链接。
3. 用独立矩阵IoU实现重算候选、GT支持和原始链接，核对分母和片段边界；同输入文件SHA保持不变。
4. 核查所有条件的最长片段代表及已知120帧；原图和叠图仅作非盲开发案例，不升级为新独立真值。
5. 输出明确结论：事件FP=0与轨迹冗余是不同指标；几何支持不能替代物理身份；不因当前结果为已见片段添加新算法／阈值。
