# 专用身份训练的下一阶段准入

状态：方案准备，尚未下载新训练样本或启动训练。先完成以下清单，再提交GPU任务。

1. **固定新的数据角色。** 当前20登记ID可作训练身份候选；从本轮未使用的其他身份中划分登记验证身份、验证未知、登记评价身份、评价未知。登记验证和登记评价身份均不参与梯度训练，验证与评价身份进一步分开；每个登记评价ID仍需要提前图库图。
2. **先看日期/相机元数据。** 训练候选取8月14–16日，验证候选取18日，评价候选取20日；实际文件可用性决定规模。相机1文件和标签先核查，使用同一身份角色贯穿日期，按预声明规则处理不足样本。元数据阶段可决定准入，不能按模型分数换人或换图。
3. **冻结普通预处理对照。** A沿用官方中心裁剪；B保留全躯干的等比缩放和填充；C与B同预处理，再加入专用训练。A/B检查预处理，B/C检查学习，避免同时换两个环节后将全部提升归因于训练。
4. **锁定训练预算。** 以现有轻量编码器为起点，明确嵌入维数、身份平衡采样、损失、增强、学习率、epoch、随机种子与checkpoint选择标准；先做单seed短跑，运行稳定后再做多seed正式对照。最终评价牛及未知牛不进入梯度、checkpoint选择、量化校准或拒识阈值选择。
5. **保留拒识分母。** 分别报告登记身份正确/错配/拒绝及未知误接收。量化后重新在允许的验证数据上校准阈值，最终评价保持冻结。多帧策略先声明K和选帧方式，再评价。
6. **连接通行级输入。** 当前400图来自作者整理的身体裁剪，后续再比较参考裁剪与实际检测裁剪；身份查询遗漏与假通行另计，完整通行N=C+W+U+M，不用当前图像实验的M0替代。

当前已经使用的40身份小样本继续作为开发与诊断材料。新训练方案和下一留出清单确定后，写入独立protocol与manifest，不能覆盖本轮阈值、评价分数或采样文件。
