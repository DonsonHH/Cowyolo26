# 标注口径与训练数据审计

2026年10月27日。本轮原计划检查真实/合成训练数据组成，再开展训练对照；重读作者定义并核查图像后，先修正了一个更基础的问题：**OpenCows训练的是躯干框，已审阅的Toros参考框覆盖了更多身体部位。此前低IoU配对结果同时受到框标注口径的影响，不能单独解释为模型没有发现牛。**

## 1 先纠正上一轮结论的范围

原始诊断数值保持原样：正常计数仍为官方6匹配、五轮2匹配、20轮三seed为1/2/1；原始框换参考ID的主阈值诊断仍为1/1/2。需要修正的是解释：这些结果是在既有参考框范围、IoU配对和区域规则下得到的可用观察，不能直接分解成纯粹的检测召回或ID关联损失。

OpenCows作者论文第3.1节定义其框覆盖躯干，排除头、颈、腿和尾巴；采集画面以室内外俯视图为主。[作者论文，PDF第8页](https://arxiv.org/pdf/2006.09205)

Toros发布说明记录了COCO预训练YOLOv8、DeepSORT初始处理及人工框/ID修正，没有明确声明躯干框规范。本轮查看的参考框覆盖头、腿及躯干，与OpenCows框范围不同；这是所审阅画面的证据，不推定每一条参考都严格遵守同一种身体范围。[发布方说明](https://data.mendeley.com/datasets/dk54zg67dd/1)

## 2 同一头牛也可能低于IoU0.5

[Toros第27帧：绿色参考框，橙色为五轮模型的实际原始检测框](<../../../ARCHIVE_CONTENTS.md#omitted>)

此例中，橙框主要覆盖躯干，绿框覆盖头和腿。数值为：

| 指标 | 第27帧、参考ID1、五轮模型 |
| --- | --- |
| IoU | 0.48409 |
| 交集 / 预测框面积 | 0.97816 |
| 预测框面积 / 参考框面积 | 0.50031 |

当一个小框完全包含在大框内时，IoU等于小框面积除以大框面积。因此，正确定位了较小的躯干范围，也可能达不到整牛参考框的0.5阈值。此例仍可能包含定位误差，但不能仅凭低IoU认定“没有检测到牛”。

本轮把“较小预测框大部分在参考框内、但IoU较低”预先定义为查看标记：交集/预测面积≥0.9，面积比在0.15–0.75之间，IoU<0.5。按每条参考行选择同帧最高IoU候选，得到官方3行、五轮248行、20轮三seed122/241/319行。

这些是逐参考行的图像核查候选，可能重复涉及同一头牛，也不是一对一检测评分。它们没有被自动加为TP，没有用于提高召回率，也没有替换原IoU诊断或计数成绩。各模型都保留最早触发标记的画面；新模型有的首例在画面边缘，不能把全部标记都归因于躯干/整牛差异。

## 4 元数据能否恢复合成母图与会话

已读取压缩包内全部7043份检测XML。其filename均与当前编号文件一致，没有发现指向另一个原图编号的filename。7017份主要包含filename/object/size，4份没有object；另22份有source/path等字段，但database均为Unknown，path的末尾仍是当前图像名。

这些元数据没有恢复完整的synthetic母图、日期或采集会话映射。此前完全相同图像的hash分组继续保留；除此之外，不能把当前随机图像划分升级为按会话严格隔离的最终测试。

另外核查了压缩包提供的10-fold-CV.json：每折包含train/test两栏，覆盖全部7043张，测试704或705张，含317–346张synthetic。以已验证的图像字节hash检查，每折有8–18组完全相同图片跨train/test。

这一发现针对**当前分发文件**，不推断作者全部论文实验实际使用了该扩展划分。我们当前的开发划分另按完全重复hash分组，并隔离19张留出重复图，因此上述作者JSON的问题没有被直接用于当前训练划分；增强母图和时间近邻关系仍未全部解决。

## 5 对后续训练和论文怎样处理

主实验先保持与现有公开标签一致的对象定义：**俯视奶牛躯干检测 → 身体参考点的通行事件 → 原始分辨率躯干裁剪 → 独立身份编码器**。当前权重中的类别名cow保持原样，在实验记录中明确它的框范围为cow_torso。模型和已有文件不改名或覆盖。

完整通行参考按同一身体参考点人工判定，记录起止截断、遮挡和并排个体。检测框用于定位与跟踪，通行是否完成由独立事件参考评分；图库身份继续沿作者匿名ID单独验证。

Toros继续保留为跨视角、跨外观的计数压力诊断。其冻结事件分数有效描述当前协议下的输出；异口径框IoU作为几何诊断，不能直接与OpenCows躯干AP合并。若要报告同口径检测AP，需另外提供范围一致的参考标注，或使用本就采用该范围的独立数据；本轮没有自动缩小Toros参考框来提高成绩。

后续真实/混合数据组成对照以相同躯干标签、相同训练更新次数和全部seed进行，先固定实验选择规则，再运行。图像开发验证与完整通行验证分别记录。最终论文还需要未参与调参的会话与可靠标注；PYNQ-Z2联合推理和能耗继续按原计划验收。
