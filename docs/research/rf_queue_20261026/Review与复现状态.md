## 1 证据与边界

| 项目 | 已核查内容 |
| --- | --- |
| 输入锁定 | 协议保存5个视觉模型的checkpoint、逐图预测SHA256和原阈值，没有重新优化识别 |
| 真值隔离 | 运行事件仅有不透明ID、时间、读区、方向、snapshot ID；期望身份只在构造扰动和评分中使用。RF登记表属于模拟可观察输入 |
| 实时截止 | 迟到记录不会影响早先关联；关联决定与迟到审计分开。批量与逐tick推进的决定一致 |
| 一对一与重复 | 同码重复不增事件；共享读数和多码冲突保持疑难；同一牛折返可用新的读数形成另一通行 |
| 失败暴露 | 强制唯一错码产生W60，没有隐藏为成功；无图为U，视觉事件缺失为M |
| 队列账目 | 所有任务保留完成、迟到、容量拒绝、等待/部分超时或会话结束待完成状态；不在前台停止后额外排空来装作在线稳定 |
| 单位与能力 | 代价为tick参数，不是PYNQ实测。可切片要求真正可恢复路径；当前完整模型调用未声称可任意抢占 |
| 独立复算 | 不导入关联器、调度器或原评分器，重算40组RF输出、180组评分以及36条资源/容量/时限时间线 |

正常RF的C60来自正确码构造，错码的W60来自错误码构造，它们是功能边界测试，不是误读概率估计。60个构造事件来自12个身份的既有60张查询，不按情景重复数扩大独立样本数。 queue层的前台截止错失仅是调度指标，没有映射成真实计数错误。
