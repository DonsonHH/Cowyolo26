# 提高余弦阈值仍只能保留很少的正确身份

2026-10-31。**在已评分的BECA固定预测上，即使利用全部标签事后挑阈值，要同时观察到W=0、FA=0，原／新编码器最多正确接受1／30和3／30。** 这说明该批数据中的问题不限于原阈值选得偏低；最高余弦分数的错误—覆盖取舍也很差。这里是观察集上界诊断，没有选出新的部署门限。

## 1. 诊断从哪项结果出发

[固定迁移评价](<../beca_fixed_transfer_20261030/固定模型外来源结果与阈值失配.md>)使用10注册＋10未知ID、90张作者OBB图，按文件名日期划分；两个固定编码器各90图，全部180次CPU前向及原始特征已经完成核验。主工作点原／新模型C13／W15／U2、C13／W11／U6，未知FA均26／30。

本次读取相同60张查询的已保存最高ID分数及作者标签，各模型按score>=threshold枚举61个可达状态，包括全部拒绝。每个相同分数组同时接受，因而没有漏掉相同阈值能产生的决定。另用直接逐查询判定及区间中点独立复算全部122状态，原分数、候选与主阈值都未改变。[完整状态](<../../../research/beca_score_diagnosis_20261031/results/score_diagnosis_v1.json>) · [独立复算](<../../../research/beca_score_diagnosis_20261031/results/independent_verification_v1.json>)

## 4. 对下一步的具体含义

当前数据支持收回“原门限可直接跨来源使用”的主张，也说明应同时研究候选排序、目标域校准与拒识能力。这里没有证明失败由毛色、栏杆、相机时间字样、标签日期或某个网络层造成；这些因素在现有来源间一起变化，仍需独立控制或更可靠目标域材料。

保留原固定评价，不根据本诊断改权重或门限。BECA这20个身份已用于评分；后续若利用这些标签做诊断或选方法，它们属于已见开发材料，需要另设独立身份／会话验证。已隔离的冲突ID不自动使剩余标签正确，文件名与相机叠字日期不一致的范围也继续披露。
