# 20个保留身份的独立组件评价：先固定协议，后打开像素

2026年10月30日。此前120个Cows身份均已用于开发，新域16个训练身份与早已保留的20候选身份互斥。主候选保持预先指定C_domain_seed26末轮、绝对余弦检索；比较对象为适配前旧C。这里先固定名单、图像选择和目标图库规模，不进行图像请求或模型前向。

最终20身份沿用域适配协议中已保存的原顺序，前10作已登记、后10作未知。注册每牛3图，查询每牛3图；注册日取截至03-04且至少3图的最早日，查询日取最晚日，跨度至少7天。当天3图继续沿用旧协议按源session均匀选择、session内取中间文件、不足时按文件名补足的规则。若任何输入不满足来源／CRC／解码或分组要求，保留失败并停止，不按结果补换牛或照片。

因此正式图库为10ID／30图，已登记查询30图、未知查询30图，共90张源图。模型权重和检索方法不再据此选择；旧C和新C都报告全部90图，不能只保留有利模型或阈值。

先用已有校准20个已登记ID原SHA顺序的前10个构造主10ID图库，保留对应30已登记查询与原20个未知ID的60查询；只用已保存特征重新计算。对每模型选择满足未知经验FA≤3／60的绝对余弦阈值，优先最大正确接受C、再最小错误接受W、再较高阈值；所有阈值及原始分数在首次保留ID像素请求前共同冻结。该10ID阈值仅属于这个正式评价协议，不修改此前20／40ID结果、同板六牛号图库或默认部署阈值。

原校准注册ID的后10个只作预先列明的校准稳定性对照，独立算其10ID阈值并一并冻结；主评价仍只用前10个阈值，不能按保留集成绩换到后10个。原MultiCam阈值0.8445389603236383及新域20ID阈值仅作附录压力，不作为保留集调参搜索。

主指标为已登记正确接受C／30、错误身份接受W／30、拒绝U／30，以及未知误接受FA／30；闭集Top-1、Top-5、接受样本错误比例作为补充。身份裁剪输入齐全时M=0仅指本组件未缺查询，不代表通行检测无漏失。按牛重采样区间与新旧同牛配对差单独报告，ID样本少，经验零错误区间退化不解读为总体零风险；不把3张同牛照片视为3个独立身份。

本组件的“独立”仅表示与身份模型训练／开发ID互斥，并在模型／检索／阈值冻结后首次打开对应身份裁剪。Cows源场景相同，部分身份裁剪关联的检测原图已用于本项目检测训练，不能称全项目完全未见像素或跨牧场最终端到端测试。检测器与身份编码器没有共享训练权重；保留ID独立性的主张限定在身份组件。03-05至03-11像素继续关闭，不用于补图；跨年真实物理牛映射仍未知。

下一阶段只有在协议、两模型SHA、阈值、代码与输入清单全部冻结并核验后，才下载这90张图并按清单执行两个模型各90次前向；无新训练、无epoch或seed筛选。完整归档、输入hash、特征、每牛分数和全部主／附录结果取回复算。评价后的任何方法改动都将这些20身份转为已见材料，需要新的留出证据。整个论文仍需独立通行事件、真实身份与系统时序证据。
