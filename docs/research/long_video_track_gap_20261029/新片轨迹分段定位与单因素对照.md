# 新长片漏计病例：关联边界定位与第一阶段单因素对照

2026年10月29日。**固定同一套检测框，只改变第一阶段关联代价，seed26在新长片的向下预测从11增至12。** 同一中断前状态的短回放恢复了原ID19，并在2675帧完成A→B事件。这说明本病例存在可操作的关联因素，下一步应先做多seed及旧片回归，再决定是否采用；不需要先靠增加训练轮数尝试解决。

原源片8912–10873帧人工确认12头、seed26预测12的达标成果保持。本轮新片仍是待独立接受的助理参考，12预测不写成100%准确率。这里完成的是病例机制和一个候选控制实验，PYNQ-Z2联合运行与论文贡献继续待验。

## 1 先让问题能稳定复现

输入来自[上一轮四模型实际回放](<../long_video_fixed_replay_20261029/普通俯视长片四模型回放与研究决策.md>)的seed26原生检测缓存。先从源帧0运行实际安装的ByteTrack，精确重现2025次更新、909条全图后处理输出、297条ROI轨迹、全部确认／待确认观察、交接记录和两条11事件计数路径。

随后保存2650帧前完整轨迹、计数器、全局ID计数器和邻牛输入，从同一状态运行2650、2655、2660、2665、2670、2675这6次更新。原实现连续两次都未恢复ID19、未产生其跨区事件，研究信号按预期返回失败码1；每次实际6步约7毫秒，Python环境启动另计。这是服务器上的诊断循环，不是板上速度。

复现命令在Slurm分配内为：

```bash
/share/home/renly/projects/idcoo_research_20261026/env/bin/python \
  /share/home/renly/projects/idcoo_research_20261026/long_video_track_gap_20261029/tools/reproduce.py --signal
```

原实现输出`FAIL_EXPECTED_BASELINE_GAP`，退出码1。该预期基于源图支持的“前后是同一条通行”助理病例判断，不是额外获得了人工身份真值。短回放保留邻牛和全部实际轨迹状态，因为删去竞争框会改变拥挤关联；没有将其宣称为每个元素都已删除验证过的最小测试。

## 2 四个解释分别得到了什么证据

在插桩前冻结[四个可证伪解释](<../../../research/long_video_track_gap_20261029/protocol/association_probe_v1.json>)，然后记录实际第一阶段矩阵、二次匹配资格、暂定轨迹、池合并和完整图像输出。插桩后全部原轨迹、观察和事件再次精确回归。

| 解释 | 实际证据与结论 |
| --- | --- |
| 原始检测缺口 | 2650／2655／2660三个采样时点，通道保留框覆盖后面的牛，领先牛无当前保留框。物理对应由原生病例目视支持，未当独立检测召回真值 |
| 重现框无法关联旧ID | 2665起，领先牛体的候选框与ID19预测框错位；第一阶段融合代价超过0.8，另一个更便宜的候选已分配给ID20。独立枚举确认实际全局分配 |
| 旧ID已过期或没有资格 | 排除“已过期／移出第一阶段池”：ID19六次均在第一阶段池中，2650由Tracked变Lost，后续仍保留。六次均无低分子集框，所以第二阶段资格不是这次重现框的恢复路径 |
| ROI把已有输出筛掉 | 排除：六次完整图像确认输出中都没有ID19，不是只有通道筛选后才消失 |

这里重现框分数均达到0.25高分界限，属于第一阶段。本病例与此前另一个[低分／Lost二次匹配病例](<../paired_event_intake_20261028/B区中断与关联门槛.md>)的适用环节不同，不能沿用同一修复解释。

## 3 代价是如何阻止原ID恢复的

当前第一阶段使用`cost = 1 − IoU × detection_score`，接受门槛为0.8。下面是原实现的实际预测框与源图病例支持的领先牛候选；候选物理对应仍属于助理事后病例判断。

| 源帧 | 候选分数 | 与ID19预测框的IoU | 实际融合代价 | 若只看当前这对框的纯IoU代价 |
| --- | ---: | ---: | ---: | ---: |
| 2665，重叠候选一 | 0.3691 | 0.2997 | 0.8894，拒绝 | 0.7003，可达门槛 |
| 2665，重叠候选二 | 0.3132 | 约0.2999 | 0.9061，拒绝 | 约0.7001，可达门槛 |
| 2670 | 0.7806 | 0.2428 | 0.8105，拒绝 | 0.7572，可达门槛 |
| 2675 | 0.6619 | 0.1859 | 0.8770，拒绝 | 0.8141，仍拒绝 |

2665／2670／2675对ID19代价最低的原始列实际对应后面的ID20，并已分配给它。不能只看到行最小值低于门槛，就认为ID19应当恢复；需要保留全部竞争矩阵。

独立实现复算了51个真实IoU／代价项，最大差约`1.50×10⁻⁷`；对六次第一阶段枚举26种可行的部分分配，最优结果与实际应用的分配一致。[原始跟踪插桩](<../../../research/long_video_track_gap_20261029/delivery/results/association/trace.json>)及[独立复算](<../../../research/long_video_track_gap_20261029/results/independent_verification.json>)保留全部数值。

上表的纯IoU列只是固定矩阵的算术比较，不能直接当作新算法结果；尤其2675仍不够。于是再做了下面的真实重放。

## 4 只改第一阶段代价，真实重放的结果

[控制协议](<../../../research/long_video_track_gap_20261029/protocol/firststage_control_v1.json>)在运行前冻结。候选只把第一阶段的代价改为`1 − IoU`：0.8门槛、同一原始框、第二阶段与未确认轨迹的分数融合、轨迹去重、ROI、原生时钟和两种计数器均不变。通过子类运行，安装包和原结果没有修改。

从完全相同的2650前快照出发：

| 时点 | 原融合路径 | 纯IoU第一阶段控制 |
| --- | --- | --- |
| 2650／2655／2660 | 无ID19观测 | 同样无ID19观测，不把预测框补成观测 |
| 2665 | 原ID未恢复 | 原ID19恢复，y=0.7048，B稳定第1次 |
| 2670 | 新ID23出现在B，缺该ID的A历史 | ID19保持，y=0.7718，B第2次 |
| 2675 | 无完整事件 | ID19保持，y=0.8197，B第3次，发出A→B事件 |

候选在2665实际采用的是0.3132的重叠候选框，不能误写为采用0.3691那一框。此前确认在2645帧，恢复于2665帧，相隔0.8秒；原有2秒间断政策保留了A区起点。**稳定观察仍是3次，并未放宽计数规则。** 原实现的研究信号为红，候选短回放为绿。

再从源帧0完整运行两种算法，每种2025更新，得到：

| 计数路径 | 群体窗口：原→候选 | 后续单牛 | 人员窗口 | 向下合计：原→候选 |
| --- | ---: | ---: | ---: | ---: |
| 仅确认后观察 | 10→11 | 1→1 | 0→0 | 11→12 |
| 确认时交接一次观察 | 10→11 | 1→1 | 0→0 | 11→12 |

所有向上预测仍为0。本轮没有真实牛反向通行的新证据。

**其他输出也发生了变化。** 按事件帧和方向的多重集合比较，新增2675与3840，原3845消失，净增1；即另一条事件提前0.2秒。多处临时ID重新编号，ROI轨迹行数297→303，全图输出909→910。不能把两个算法中的相同数字ID当成同一头牛，也不能写成“其他事件和跟踪完全不变”。

独立按ID稳定区间扫描复算了两完整条件、四条计数路径及600个原生ROI中心，均与真实输出一致；短回放的B稳定序列1、2、3和2675事件也核对通过。[控制原始结果](<../../../research/long_video_track_gap_20261029/control_delivery/results/firststage_control/summary.json>)和[独立验算](<../../../research/long_video_track_gap_20261029/results/control_independent_verification.json>)可查。

## 6 下一步按什么顺序做

1. **先做回归，再决定采用。** 固定本轮纯IoU第一阶段候选，在新长片其他seed、原片人工12头对应三seed及已用Toros真实反向片上成对运行。保留官方及原算法对照、所有新增／消失／时间变化和拥挤双牛病例；原12头成功模型继续保留。
2. **在真实参考下评价。** 新片参考先由独立人员接受，再按冻结规则逐事件核对。当前原12头总数验收有效；它不等于新片事件参考已接受，也不等于新算法的原片回归已做。后续最终留出按会话／日期／相机在调参前冻结。
3. **训练由错误证据决定。** 此例的固定框重放已产生恢复，先研究关联更直接；若多个普通俯视会话持续出现原始框缺口，再用已审计公开标注固定预算训练、比较三seed与旧模型。不能因此宣称无需更多检测训练，也不返回鱼眼数据路线。
4. **继续完整系统目标。** 补同一俯视通道真实双向、事件抓拍与独立花纹身份编码／图库／未知拒识；耳标缺读触发的身份查询和前台检测最终都在PYNQ-Z2执行。连接与版本信息到位后实测联合延迟、队列、丢帧和能量。这个关联配置控制本身不作为新颖论文贡献，论文仍需完整实验与已有方法比较。
