## 2 当前演示说明了什么

按冻结的40%/60%区域、3个稳定样本、2秒丢失上限重新回放实际轨迹，本段官方模型产生0次通行预测，五轮训练模型产生7次A→B预测。独立实现重算得到相同的事件帧、方向、轨迹号和时间。

这些结果表明公开牛体框标注能帮助模型适应本片俯视画面。7次是预测通行，准确率要与独立事件参考比较。相机中的A→B尚未绑定牧场实际“进入”语义。模型的track编号只是片内跟踪编号，奶牛档案身份由另外的花纹编码器负责。

此前Toros外部片段仍保留官方6/6、五轮模型2/6的冻结结果。两个片段上的表现差异说明，训练和模型选择需要同时观察域内俯视画面与外部场景。

## 3 你的建议如何进入后续步骤

不需要先给这段视频补牛体框才能继续训练。现有OpenCows2020已经提供牛体框，MultiCamCows2024已经提供匿名身份裁剪；两种标注分别训练检测器与身份编码器。

1. **继续检测训练。** 在已审计、裁剪越界框的OpenCows2020派生训练集上训练YOLO26n，保留官方和五轮模型；训练配置、随机种子、实际checkpoint及选择规则先固定。当前训练5913张、验证370张，原片不进入梯度更新。
2. **套回指定原片。** 对8912–10873帧推理并保留完整输出，展示遮挡、相邻牛、碎轨迹和漏检处。更新预览时明确模型版本，不以调参后的片段称为全新测试。
3. **分别验收计数和身份。** 看检测框可以先推进；论文计数准确率需要逐事件参考，身份正确率需要查询牛与图库ID的可靠对应。独立复核JSON到位后再给出TP/FP/FN。
4. **继续部署数值检查。** 本轮QAT导出还有1/8训练向量未通过固定容差，先处理该问题，再运行完整QAT和浮点继续训练的配对实验。详见[量化检查](<../qat_study_20261026/QAT导出检查与后续训练.md>)。
5. **进入板上联合验证。** PYNQ-Z2连接、镜像与工具版本到位后，核对单模型数值，再测检测和后台身份任务共同运行时的时延、内存、队列和能耗。

当前OpenCows图像划分已隔离字节完全重复，合成图与真实母图、时间近邻关系仍未全部核清，继续作为开发划分。最终论文需要新的会话或场景留出。
