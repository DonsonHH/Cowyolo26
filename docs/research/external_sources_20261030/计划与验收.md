# 公开真值来源复核：先准入，再决定推理

2026年10月30日。当前主线仍缺普通俯视的独立事件和永久身份；本轮不再按已反复使用的12头片段调参，也不把预测文件当GT。原192模型、计数规则与图库不变。

1. 元数据阶段只获取作者仓库、数据卡、文件目录／schema／标注说明及许可，不读取新图像像素、不运行模型。固定候选为COLO、AutoCattlogger样本、CattleEyeView；保留因访问限制或标签不足而不能准入的材料。
2. COLO只作为外来源检测候选。后续只用作者明确标识的Top-View，侧视不加入本项目俯视训练。先核查正式标注、对象边界、分区重复及来源；没有轨迹／时间／方向便不升格为通行GT，没有永久ID便不升格为ReID评价。
3. AutoCattlogger优先检查公开单牛剪辑及CowID顺序表是否真实存在、对应哪天／哪段、是否截断。单牛切片、某些额外半身牛和身份顺序不能自动当连续通道的逐事件参考。CattleEyeView只读访问入口，不提交表单或联系作者。
4. 不使用他人OC-SORT／SAM等预计算输出作正式真值。作者提供、自动生成、人工复核及数据是否已下载分别记录，不能据README字段名判断GT。
5. 新像素／模型推理必须在元数据和用途准入后再冻结协议；可继续比较已经固定的官方YOLO26n、旧192直角seed26和新mosaic0.5主seed26，不能依据新集成绩换seed。已有最终留出日期仍不打开。
6. 输出源快照、文件与标签审计及Markdown自审。新公开素材不等于未见独立测试，先查本项目是否已使用及训练来源交叉；不足之处明确为待验证。完整板端归档通过UART只读回收，与新数据工作分开，不重跑已有实验。
