# 固定特征上的拒识分数：先校准再比较开发覆盖率

2026年10月30日。域适配的Top-1改善，但绝对余弦阈值使正确接受率偏低。本轮复用全部已存特征与按牛分数，比较三个预先固定的一维分数；没有新推理、训练、最终ID图像或板端修改。这是已看数据上的方法开发，不能称新的未见测试。

模型固定为原C编码器及M_continue／C_domain的seed26／27／28，共7个。主候选仍为预先指定的C_domain_seed26，不按本轮方法或seed的开发成绩换主模型。

同一图库检索排名保持不变。对最高、次高**不同牛号**的相似度s1、s2，固定三种分数：A绝对s1；B差值s1−s2；C距离比置信度`1−d1/d2`，`di=sqrt(max(0,2−2·clip(si,-1,1)))`。d2≤1e-12时C定义为0、表示无法区分，不出现NaN。分数越大越接受。C与开放集最近邻距离比文献相关，本项目只实现这里的固定公式，不冒充原论文完整实验复现或新算法发明。

每模型／方法只在原20注册／20未知校准组（60已登记／60未知查询）按既有规则选阈值：未知误接受≤3／60，最大正确接受C、平局最小错误接受W、再较高阈值。主候选的方法仅按这组校准的C、W选择，平局按A、B、C的顺序；先共同保存全部21阈值与唯一主方法，才计算任何新方法的开发决定。不用两个开发组挑方法或改阈值。

之后报告原两个固定20ID开发组（每组60已登记＋相同120未知）、完整40ID压力和原6ID图库的MultiCam保留能力。注册图库20时才与校准规模匹配；40／6只作规模和来源压力。7模型×3方法×4范围=84条件，全部保留，不合并重复未知查询或将低错误的全拒绝条件叫成功。C／W／U、未知FA及按牛区间和相同查询的配对差同时报告。

最大相似和两类间距是置信代理，不能由经验5%保证新域总体错误率。若新方法改善，先冻结其代码／阈值，再在同一已存图像上检验NCNN与实际PYNQ，最后才准入保留20ID；当前12通行的永久身份、独立事件JSON与现场输入缺口不变。
