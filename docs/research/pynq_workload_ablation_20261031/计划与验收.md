# 补齐同负载的高分输入与身份工作量对照

2026-10-31。已恢复的实际触发四轮完成4.630–4.770FPS、计数10／10／8／7，35身份任务随计数变化。下一步检验高分JPEG取得和后台身份工作量的时序作用；这项控制不替代实际触发评价或独立事件真值。

既有阶段分别验证过串行／异步输入、按帧暂停／持续后台、CPU亲和性，以及无逐帧高分生产者时的固定10照片负载。尚缺在同一新boot、相同固定身份任务与输入时钟下，交叉分离逐帧高分生产者和后台服务工作量的对照。历史不同阶段的均值不能拼作因果证据。

采用同一192检测器、O8、跟踪与计数、392个200毫秒时隙及相同低分辨率已就绪输入。选择原默认身份编码器及匹配图库，不做新旧模型选择；各轮都启动同样的单线程、nice+10、CPU0/1后台，并各做一次相同网络预热，使编码器驻留与子进程存在保持。因素I是额外逐帧取得并验证392个高分JPEG（含前台跳过帧）；因素W是向该后台发布0或10个已有固定任务。10任务的照片、身体框、源hash和相对发布时间保持，不按本轮计数增减。

| 条件 | 正式高分生产者 | 正式后台身份任务 | 目的 |
|---|---|---|---|
| A | 无 | 0 | 编码器已驻留的前台参照 |
| B | 有 | 0 | 输入取得／校验／缓冲的增量 |
| C | 无 | 固定10 | 固定身份工作量的增量 |
| D | 有 | 固定10 | 两种负载共同存在 |

顺序冻结为A→B→C→D→D→C→B→A，每轮约78.4秒，共8轮。两次重复只量化同源设备波动；不认领跨会话统计显著性。各轮开始前做相同的源JPEG完整性读取并记录该缓存前提，期间再实际读取被释放数据；不清全局cache、不关闭swap、不改CPU频率或全局调度。

因素I包含生产线程读取、SHA校验、有界银行、当前帧固定／取回与前台到达等待；它不是对单个系统调用的纯消融。固定后台仍从原文件取得同照片，避免I因素改变其图片或tensor。前台不做按本轮事件选择的不同照片，所以本阶段是资源归因控制，不声称完整因果抓拍或现场双流达成。

正式前向预算：定时检测最多3136图，先8个既有O8锚点准入、每轮2图检测预热；8个后台各1图身份预热，4个W开启轮次各10正式身份图。预算上界3208次板端模型图前向，未计入任何未知转换器行为；本阶段不转换、不训练、不访问留出身份。所有固定身份输入与既有实际ARM／CPU参考一致时复用其数值证据，不为相同输入重复CPU前向。

新boot下先只读确认身份、镜像、服务、进程与锁。若当前不是O8，正式测试准备会在持锁后明确加载原accepted O8；记录原状态及该加载动作，不把它写成“从重启后一直未改变”。不修改现有权重、库、bitstream文件或默认Notebook。

验收：全部实际raw与既有同帧O8逐字节核对；实际处理和跳过覆盖392时隙；输入生产／接收时序、后台工作量、每图输入／特征／分数及完整计数路径独立复算。保存超200ms、P95、排队／完成、进程／全局换页计数与全部不利结果。若吞吐接近5仍迟到或未计12，保持未达完整目标。异常保留原进程句柄和原文件，不因观察超时重启模型实验。
