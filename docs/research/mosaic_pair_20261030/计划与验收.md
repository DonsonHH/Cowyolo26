# 192直角模型：mosaic概率1.0／0.5的三seed配对训练

2026年10月30日。训练覆盖审计表明，低亮度与低对比代理在原图及实际增强输入中均不少；不能据单例宣称“缺少暗色牛”。真实mosaic1.0加载器一轮提供20292个框，其中5466个短边<24像素、1949个<16像素。这里测试的假设是：减弱拼图增强可能改变小模型对原生通道图的适配；这些数字不证明mosaic是漏计原因，也不证明0.5最优。

1. 两个配置仅改变`mosaic`概率：原1.0与固定0.5；各seed26／27／28，共6个新训练。都从同一官方YOLO26n初始化，192、额外均匀直角旋转、6809训练图／8888框、1571开发验证图／1864框、batch32、AdamW、10轮及其余常规增强全部保持。没有源片／Toros帧进入训练，不读保留日期像素。
2. 先做两配置各两次真实CUDA优化更新短跑，检查模型初值、损失、梯度、图像／框有限值与面积，再丢弃短跑权重。只有短跑通过后才启动正式数组，最多3个GPU任务并行。
3. 每个正式训练保存真实2130批、1225更新、68090次图像呈现的记录、逐步有限梯度门禁、实际直角抽样和优化器日程。每epoch落盘，避免收尾失败丢失全部观察；NumPy数字序列化先以真实类型检查。不同mosaic分支会改变加载器随机调用与组成，因此不声称两分支的逐像素增强样本完全相同；共同初值、步数及全部其他参数明确记录。
4. 六组都使用末轮last.pt，所有权重共同冻结后统一回放原片、Toros与开发验证，报告每seed和不利结果，不按原片12头挑权重。输入仍为已冻结通道裁剪，计数／跟踪阈值保持。原片只报人审总数差，不写缺失的逐事件F1；Toros仍是侧视压力对照。
5. 原始训练标签保持：02191图的高度相似双框已经回查发布方XML，暂列疑似重复，不凭一个代理自动删除，两个训练分支使用相同标签。该单例也不能解释全部漏计。
6. 开发结果有足够支持后才重新量化并验证实际O8；服务器模型或输入采样频率都不当作PYNQ帧率。现有192同板版本保持，身份网络与拒识门限不变。

本文件先固定范围和决定；实际短跑、正式训练和评价状态分别由对应原始记录证明，不能将计划写成已训练或已改善。

实际执行：4次丢弃短跑更新通过；130622六组各10轮训练已完成，共7350正式更新。第一次评价130628在新模型图像推理前因旧缓存元数据字段缺失而失败，130629探针确认其余所有值／ID／事件一致；130630补字段后保持严格回归，完成25350次图像前向与36计数路径。原片1.0三seed为10／10／10，0.5为10／10／11；反向5Hz为1／1／0→3／3／0。130631媒体与130632参数控制核对完成。预先固定的mosaic050_seed26仅保留为量化候选，未替换板端模型；两条训练pin-memory线程异常标题在完成文件之后出现，根因仍待核查。完整结果和自审另见本目录报告。
