# 实际计数触发的旧新身份模型同板对照

2026年10月30日。两套身份编码器已完成固定10照片负载和同90图完整ARM核验。本阶段回到实际检测／跟踪／通行触发，沿用公开原片8912–10873、人工总量12、192检测mosaic0.5主seed26及既有O8。按旧—新—新—旧四次，每次392个200ms时隙／78.4秒；低分输入已就绪，前台主线程及后台可用CPU0／1，后台nice+10、NCNN单线程，持续运行不逐帧暂停。

每次独立按实际已处理帧重建跟踪／计数，通行产生后模拟RFID全部未读，提交一项身份任务；没有固定发布10照片或补足任务。跳过时隙不能补入检测或轨迹，任务数与照片可随运行变化，完整记录；四次全部保留，不按计数、接受数或时序选一轮。原片独立逐事件和永久身份未补齐，不输出计数F1或真实身份恢复率。

采用既有发布门控高分JPEG生产者，每个规定时隙实际读取／SHA，最多保留最新6帧加1个正在使用的帧。选择器只使用过去1秒、最多6个已处理帧的当前临时轨迹，几何面积／边界／重叠公式不变，不读取未来帧或图库分数。后台按已选择JPEG和实际框解码、裁剪、旋转、PNG0、身体预处理、真实编码及检索，并保存input／raw／归一化／分数NPZ。低分输入就绪与高分文件读取、输入预检已读文件、无真实相机／RFID都明确计时范围。

两模型读取各自固定NCNN权重与自己编码的相同30张Aug19登记照片；查询为Aug14回放，仍属回顾检索。新图库复用上次40图资格核验中前30张实际ARM特征，整个源文件SHA固定；不能把新查询配旧特征。主阈值共同保持原MultiCam0.8445389603236383，附加固定Cows0.8707458695890389只报告保存分数的决定，不选择阈值或调参。当前6ID图库不使用新10ID组件评价的阈值。

先核查当前设备、两模型／库／图库SHA、O8、锁和已知自有任务终态。在正式周期前运行一次8个O8资格向量；四次各2个O8预热、各1个身份预热。正式O8最多1568次，正式身份前向数等于实际成功入队任务数；不为达到预期数重跑，预热和参考另列。启动与进程观察必须绑定原PID，超时先查原任务，保留失败。
