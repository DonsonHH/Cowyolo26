# 检测器输入尺寸 × 直角增强：训练因素对照

2026年10月29日。上一轮完成8380源图配对、13381实际检测和输入控制，发现当前640条件适配不足，已改变下一步训练优先级，属于实际进展。本轮执行已约定的9候选，原12头成功版本保留。

1. 固定原6809训练图／8888轴对齐躯干标签、1571开发验证图／1864标签，初始化仍为同一官方YOLO26n。保留既有320无额外直角增强的3seed历史控制；新增640无增强、320直角增强、640直角增强，各seed26／27／28。所有候选10轮，末轮last.pt统一使用，不按原片计数或best.pt挑模型。
2. 训练batch32、AdamW、学习率／梯度积累／warmup和原数据增广保持，只有输入尺寸与额外均匀0/90/180/270度整步旋转两个因素。旋转发生在标准训练批预处理之后，同步旋转像素与归一化xywh框；平方输入无插值，不额外放大包围框。旋转有独立确定性随机流，不消耗原训练随机流；验证数据不加该增强。
3. 先核对实际安装版本的预处理代码，再在CPU／CUDA验证四方向、任意对象排列、空标签和像素／框掩码对应、面积与逆变换。用真实训练器完成三组各2次有限损失／梯度／优化更新的短跑，记录并丢弃，不用其权重启动正式训练；无增强分支与标准预处理核对。
4. 通过后以Slurm数组最多3个GPU候选同时训练。每个记录初始参数摘要（应与历史同seed相同）、实际批次／优化器更新、直角抽样次数及完整日程、有效参数、CSV和权重。每次训练有独立新目录；不覆盖旧图像、标签、模型或结果。
5. 9个候选全部完成并冻结后，按预先固定输入范围比较开发图两尺寸／两方向，保留每seed和不利结果；之后同样计数链路回放原片与已用Toros反向6参考。原片人工12头是已接受开发里程碑，不能用来选择只报最好seed。新长片及独立身份参考仍按原计划，不将训练内验证AP当系统通行准确率。
6. 完整检查训练更新、标签／旋转几何、所有候选结果与媒体后自审，更新Markdown研究入口。服务器训练／离线时间不当板上指标；PYNQ-Z2前台检测与后台身份共同运行目标保持，板卡信息仍按用户约定稍后提供。

全局运行模型暂不改变。1400开发保留与622最终日期候选像素不纳入本轮训练／调参，身份编码器与RF逻辑保持。
