# COLO外来源检测：先固定协议，再一次性比较

2026年10月30日。本轮不训练，比较预先固定的官方YOLO26n、旧192直角seed26、新192 mosaic0.5 seed26；每个模型均在192／256／320输入下运行官方Top-View测试50图，共450次图像前向。两个微调模型仍是192训练的同一套权重，改变测试输入不等于训练了新的256／320模型。

数据版本为COLO官方v1.0.0的COCO导出。已有来源准入报告、22份标注核查及8训练图视觉QA；本协议在首次请求测试50图像素之前写出。完整名单、归档成员CRC、标签与模型SHA由`protocol/run_v1.json`冻结。既有Cows2021最终留出日期继续不开启，不按本轮成绩换seed、门限、图像或模型。

原始451标签原样保存。主评价隔离已知零面积annotation127，其余450框与预测都裁到640图像边界，并重算框面积；另列保持450正面积原始GT坐标的敏感性结果，不能把15个轻微越界标签静默删除。所有50图保留，原始／处理后标签hash与逐标签变换记录存盘。参考框包含推断遮挡部分，和现有躯干框训练不完全一致；报告这一口径差异。

RGB输入按固定OpenCV线性缩放到正方形、CHW float32／255，不裁ROI、不旋转、不增亮，不作测试增强。三个模型以Torch CPU直接eval前向，使用其端到端300候选输出，不额外NMS；官方cow类19与单类cow0均映射成评价cow0。保存完整raw和实际输入hash；不调用会隐式预热的predict接口，没有预热。计数forward hook核对45个十图批次／450图，任何额外计算须明示。

评分使用冻结pycocotools wheel的COCO bbox评价：IoU0.50:0.05:0.95、101召回点、maxDets1／10／100，最低预测分数0.001，按cow类。报告AP、AP50、AP75、AR100及光照分组。另用事先固定conf0.20／IoU0.50作逐图一对一匹配，按置信度下降、最高IoU优先，记录TP／FP／FN和图像框数MAE；它不是通行计数MAE，不据此计算事件指标。完整450正面积框与所有50图均进入主分母。

验收要求：下载每张JPEG与官方ZIP的CRC／尺寸一致；模型SHA、协议与代码先冻结；实际前向在Slurm CPU分区，退出0并取回raw／日志；本地从完整raw重新解码、复算固定点指标，另保存COCO evaluator数组与库版本；按事先文件名顺序固定抽查图像，不因预测好坏挑图。描述单来源50图，不作跨牧场显著性、永久身份、现场RFID或板端速度结论，也不自动替换默认权重。

服务器只运行这次离线对照。PYNQ-Z2已有O8三尺寸与同板身份运行记录保留；网口仍无载波，本轮没有新增板端运行。数据、包依赖和结果均放在本任务目录，不修改已有环境或其他作业。
