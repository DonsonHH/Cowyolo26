# 普通正上方俯视：新视频会话准入与固定模型回放

2026-10-28。上一轮接受用户人工确认的12头并冻结达标候选，属于实际进展。本轮扩展到普通俯视视频，停止鱼眼分支投入，保持既有12头版本。

1. 只用Cows2021官方原视频目录，从元数据先选择4个尚未使用的会话。不打开2020-03-11保留日期；排除既有两段及与实际8380张开发图源时间戳±10秒重叠的会话。其余213个按时间排序取首、约1/3、约2/3、末位；选择与结果无关，清单已固定在`protocol/sessions_v1.json`。
2. 每段视频下载上限100MiB，总上限400MiB；绑定来源、字节、SHA256，留存失败。登录节点只用于传输和元数据；解码和推理由Slurm完成。
3. 在模型预测前检查原生画面、解码、真实时钟和截断。按通道几何固定相机方向与ROI，不用预测结果选择。发布视频没有逐帧计数GT，本轮不假称已有独立事件参考。
4. 同一固定seed26权重、640输入、5Hz、3次稳定观察、2秒中断上限和确认前观察交接，用官方YOLO26n作对照。相机的像素尺寸／轴向校准另列，保持模型和逻辑一致；正式执行协议在看原片之后、预测之前写定。
5. 保存全部4段和两模型的结果，负结果与截断一起报告。只有明确参考后才计算准确率；当前源片12头人工参考与候选不改写，不为新视频调参后仍称未见测试。

验收包括：来源和划分核查、Slurm终态、全部视频完整解码、真实原生帧目视、模型／计数契约与输出核对、媒体／链接可用和自审。新视频的初步结果用于外部会话诊断；完整双向覆盖、个体身份和PYNQ-Z2联合实测继续按原目标推进。
