-------OpenCows2020 dataset-------

This dataset accompanies the paper - "Visual Identification of Individual Holstein Friesian Cattle via Deep Metric Learning" available at: https://arxiv.org/abs/2006.09205
It consists of two components: (a) detection and localisation, (b) identification.
For an overview of this dataset, refer to Section 3 in the paper.
For any queries, contact the corresponding author in the paper.
For accompanying source code, check out - https://github.com/CWOA/MetricLearningIdentification
We recommend any text editor (e.g. notepad on Windows) for inspecting .txt, .xml and .json files.

--(a) Detection and Localisation-- (Section 4)

/detection_and_localisation/images/ (7,043 files) - note: images after '003707.jpg' are synthetic
/detection_and_localisation/labels-darknet/ (7,043 files) - labels in the YOLO/darknet form (one line per object: element 0 = class ID, elements 1-4 = object centre and dimensions (x,y,w,h) with values scaled between the image dimensions
/detection_and_localisation/labels-xml/ (7,043 files) - labels in XML/VOC form
/detection/and/localisation/10-fold-CV.json - random splits used for 10-fold cross validation
