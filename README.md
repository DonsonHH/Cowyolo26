## 文件结构

| 目录 | 内容 |
|---|---|
| `docs/` | 为 GitHub 阅读转换了本机链接的 Markdown 副本 |
| `research/` | 本地成果原件：报告、代码、协议、配置、指标、日志、小图表 |
| `server/` | Slurm 项目补充源码、配置、结果表、日志与环境说明 |
| `pynq/` | 板卡项目及复用 O8 支持源码、配置、实测与失败记录 |
| `archive_inventory/` | 逐文件来源、SHA-256、筛选范围和校验记录 |
| `user_inputs/` | 用户提供的初始背景与归档范围说明 |

用户要求排除大模型和数据集。早期按扩展名、体积及目录筛选的归档没有完全实现“无数据／无缓存”：部分作者标注、衍生像素和依赖目录已经进入历史树，具体范围见 [归档范围与校验](ARCHIVE_CONTENTS.md)。本轮不再添加原视频、训练图像、完整标签或大模型；投稿材料采用独立的明确清单，历史证据保留。2026-11-09在私有存储完成完整性与可读取性核验后，清理了经确认的本地副本；私人恢复索引不放到公开仓库。

历史报告中的“下一步”“当前”“待恢复”等按当时阶段理解。最新实机数据以[2026-11-10完整审查](docs/research/submission_20261110/项目全流程与科研审查.md)为准；2026-11-09的V4仍保留为历史证据。研究结论尚不等于可靠身份找回或论文正式投稿就绪。

原件与便于阅读的副本分别保留，避免链接转换破坏历史校验。第三方代码与材料保留各自原许可证及来源，仓库已有 [LICENSE](LICENSE) 不替代第三方许可。
