## 文件结构

| 目录 | 内容 |
|---|---|
| `docs/` | 为 GitHub 阅读转换了本机链接的 Markdown 副本 |
| `research/` | 本地成果原件：报告、代码、协议、配置、指标、日志、小图表 |
| `server/` | Slurm 项目补充源码、配置、结果表、日志与环境说明 |
| `pynq/` | 板卡项目及复用 O8 支持源码、配置、实测与失败记录 |
| `archive_inventory/` | 逐文件来源、SHA-256、筛选范围和校验记录 |
| `user_inputs/` | 用户提供的初始背景与归档范围说明 |

按用户要求，模型权重、数据集、原始张量、逐帧媒体、依赖缓存和大体积传输包不上传；原路径、来源、配置和已有校验信息保留。原始文件没有从本机或服务器删除。

历史报告中的“下一步”“当前”“待恢复”等按当时阶段理解。最新实机数据以 [HANDOFF.md](HANDOFF.md) 列出的证据为准；研究结论尚不等于可靠身份找回或论文投稿就绪。

原件与便于阅读的副本分别保留，避免链接转换破坏历史校验。第三方代码与材料保留各自原许可证及来源，仓库已有 [LICENSE](LICENSE) 不替代第三方许可。
