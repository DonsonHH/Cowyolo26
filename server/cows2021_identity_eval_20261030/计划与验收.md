# 冻结编码器的Cows2021跨日期开放集评价

2026年10月30日。按已完成的身份来源准入，比较两个预先固定模型：B同架构ImageNet身体特征、C当前已上板的letterbox seed26编码器。不训练、不换seed，不加载作者未知训练覆盖的旧身份权重，不因新成绩替换板端阈值。

只用官方Identification/Test、日期≤2020-03-04的图像。候选ID在至少两个相隔≥7天的日期各有≥3图；按`Cows2021-open-identity-20261030-v1:`＋ID的SHA256排序，前20校准已登记、后20校准未知，再40评价已登记、40评价未知。四组ID互斥，不按图像花纹或预测选牛。每个已登记ID取合格最早日期3图作图库、合格最晚日期3图作查询；未知ID仅下载最晚日期3查询。各日优先均匀选会话、每会话取中位文件，不足再按文件名补齐。详细名单、540图及官方CRC在首次请求新身份JPEG前冻结。

每模型校准阶段180图（60图库、60已登记查询、60未知查询），评价阶段360图（120图库、120已登记查询、120未知查询），两模型共1080图像前向，无预热。图库早于已登记查询；每牛3图不是3个独立牛／通行。作者目录ID有命名空间，不冒充牧场耳标或跨年物理ID互斥。

模型、图库策略和224身体预处理固定。先完成两模型所有校准特征，在校准查询上按既有规则选择每模型拒识阈值：最大化已登记正确接受数、经验未知误接收≤0.05，平局最小化已登记错误接受、再取较高阈值。把阈值、校准结果和hash共同保存后，才运行任何评价特征。同时报告原MultiCam阈值直接迁移，3图图库与原5图不同。经验≤0.05不是总体风险上界。

公开裁剪由Pillow解码，保持既有body_tensor含224补边、RGB127和ImageNet归一化；不旋转、增亮、裁ROI、测试增强。批量Torch CPU直接eval前向，hook记录全部图数与调用数，没有predict隐式预热。保存完整raw／归一化576维特征、输入张量hash、校准冻结与每查询按牛max-cosine分数及决定。

像素准入必须逐图检验ZIP CRC／尺寸／完整解码与hash；解码重复跨不同ID或图库／查询时先隔离并停止评分，不按预测替换样本。相同ID同日的近邻图相关性报告，不将其当独立统计重复。与本项目原先身份输入的精确像素重复也检查；源检测原图关联单列，不声称完整流水线独立。

已登记报告Top-1、Top-5、正确接受C／错误接受W／拒绝U；未知报告误接受FA。已提供的裁剪查询有`M=0`，不代表完整通行无漏检。按牛聚类bootstrap2000次，seed26，已登记／未知分开，保留全部模型和阈值策略；不在评价上选模型、阈值或方法。独立程序从完整特征复算相似度、阈值和全部决定，原540图片与固定样例可追溯。
