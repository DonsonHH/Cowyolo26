-------Cows2021 dataset-------
This dataset accompanies the paper "Towards Self-Supervision for Video Identification of Individual Holstein-Friesian Cattle: The Cows2021 Dataset" at: https://arxiv.org/abs/2105.01938

It consists of three components: (a) Detection and localisation, (b) Identification, and (c) Weights.
For an overview of this dataset, refer to Section 2 in the paper.
For any queries, contact the corresponding author in the paper.
For the accompanying source code, check out https://github.com/Wormgit/Cows2021.
All data were gathered from 5 Feb 2020 to March 11 2020. There is no data on 6,7,8,9,17 and 30 Feb. 



---(a) detection and localisation---

DESCRIPTION: 
10,402 jpg images and their annotation files (XML and JSON). They were split into the train, validation and test sets. 



---(b) identification---

DESCRIPTION: Training and validation set
Orientation-rectified RGB image regions associated to the videos below and a JSON file splitting the images to train and validation.  

DESCRIPTION: Test set
13,784 orientation-rectified RGB image regions associated to 181 individual Friesian cattle.

DESCRIPTION: Videos
301 videos gathered from 4 days (08 Mar 2020 to 11 Mar 2020) for generating the training data for identification.



---(b) weights---

DESCRIPTION: Detection
Trained weights for detecting cattle and extracting orientation-rectified images.  

DESCRIPTION: Identification
Trained weights for testing the accuracy of individual identification.
