# 恢复实际执行的v7源码

[绑定清单](qualified_v7_source/binding.json)来自运行前已冻结的源码包，原包SHA仍与快牛完整实机冻结记录一致。48个文件已在新空目录重建并逐一核对SHA256，新增模型推理0次。模型、视频和数据不在该源码包内。

当前分支在实机之后修复了`take_after`的未来序号API边界，并继续开发可选的关联与补检；实际v7的调用始终使用上一返回序号。为保存实机时的精确版本，所有与当前分支有差异的文件均另存为`qualified_v7_source/*.source.txt`，其余文件直接使用仓库中SHA相同的版本。绑定清单逐项说明来源并重新核对48项，未把后续修复冒充为旧实机执行。

恢复时在**新目录**按清单复制48个文件：`source=repository`从仓库相对路径读取；`source=archived_override`从指定归档文本读取。写入前核对每个文件的`sha256`，按清单键保留目录结构；任何指纹不符即停止。该操作只恢复源码，运行所需模型、依赖和固件仍按原冻结记录准备。
